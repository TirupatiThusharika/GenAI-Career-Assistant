\# 🤖 GenAI Career Assistant



An AI-powered resume analysis and career guidance web application built with \*\*Python, Flask, Gemini AI, and PyMuPDF\*\*.



The application allows users to upload their resume as a PDF and receive personalized AI-generated insights including a resume score, technical skills, career roles, skill gaps, and a learning roadmap.



\---



\## ✨ Features



\- 📄 Upload resume in PDF format

\- 🔍 Extract text from resumes automatically

\- 🤖 Analyze resumes using Gemini AI

\- 📊 Generate an AI-based resume score

\- 💻 Identify technical skills

\- 💼 Analyze work experience and internships

\- 🎯 Recommend suitable career roles

\- 📈 Identify skill gaps

\- 🗺️ Generate a personalized learning roadmap

\- 🎨 Responsive dark-themed user interface

\- ⏳ Loading animation while AI analysis is running
